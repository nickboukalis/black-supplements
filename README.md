BLACK Supplements
A work in progress storefront for a supplement brand my friend and I started. We make a pre-workout and a creatine, mix them ourselves, and have sold to people in person. This is the site that will eventually sell them online.

This repository is a design mockup, not a working store. Nothing on the page can be purchased, there is no payment processing connected, and every review shown is placeholder text written to fill the layout rather than real customer feedback. The page carries a banner at the top saying so.

What is here
One self contained HTML file with the styles, scripts and images all embedded, so it opens in a browser with nothing to install and no build step.

The page covers the product lineup, pricing for the pre-workout, the creatine and a bundle, a supplement facts panel, a subscribe and save option, and an FAQ. The cart adds items and tracks a total, but it stops there, because the checkout is not built yet.

Why the design looks like this
The brand idea is that the pre-workout turns the drink jet black, from activated charcoal that is actually in the formula rather than added as a dye, so the whole site is built around that. The part I cared most about is the label section, because the reason we started making our own was that we were tired of products hiding small doses behind big branding, and a site for a brand like that should show every number on the label instead of burying it.

What is left to do
Checkout and payments, real product photography to replace what is in there now, real reviews once we have enough customers to ask, and the auto renewal terms that the subscribe option will need before it can be switched on.
